# Проверка версии 0.1.0-alpha.4

6 октября 2026 года проверены файлы публичной сборки. Игра не запускалась; проверка загрузки сохранений и длительной кампании ещё предстоит.

В каждой категории, охваченной проверяющими скриптами, подтверждённые ошибки исправлены. Это проверка файлов, которая не воспроизводит работу движка и не гарантирует отсутствие всех причин вылета.

## Ограничения

- Цепочка испанской гражданской войны со страной SPF временно отключена: семь событий используют отсутствующую страну. Добавление её в реестр требует отдельной проверки совместимости сохранений.
- В основе отсутствуют 168 файлов состава стартовых армий. Ссылки на них убраны; полноценных войск для этих стран и дат обновление не добавляет.
- Убраны вызовы отсутствующих событий и эффекты незавершённых веток. Эти цепочки могут быть неполными; удаление ошибочных действий не восстанавливает недописанный сюжет.
- Остался неиспользуемый файл истории `ARB - Arabia.txt`, который не подключён к списку стран.
- Карта содержит несколько цветов, не сопоставленных с таблицей провинций. Один из этих цветов есть и в карте основной игры. Их назначение не установлено; карта не перекрашивалась.
- Инвентаризация отмечает 23 пустых файла-заглушки. Ошибок чтения изображений после исправлений не найдено.
- Проверка файлов не подтверждает устранение всех ошибок записи сохранений. В окне нового сохранения необходимо вручную ввести имя файла.

## Повторная проверка

Нужен Python 3.10 или новее. Из корня репозитория:

```powershell
python tools/audit_mod.py "mod/Ultimate Ultimatum - Znamena idey" --output audit-results.json
```

С установленной основной игрой можно добавить `--base "D:/Games/Victoria 2"`. Отчёт [audit-results.json](audit-results.json) содержит результаты текущей проверки. Код возврата 0 означает отсутствие распознаваемых скриптом ошибок.

`interface/credits.txt` и `history/units/v2dd2.txt` содержат сведения об авторах и дневник разработки; они исключены из игрового синтаксиса. Скрипт не запускает игру и не обращается к сохранениям.
