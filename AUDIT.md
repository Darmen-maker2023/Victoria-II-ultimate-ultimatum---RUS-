# Проверка версии 0.1.0-alpha.5

Проверка выполнена 9 октября 2026 года по файлам обеих установленных сборок. Игра не запускалась, сохранения не редактировались.

## Что обнаружено и исправлено

В основе были структурно неверные решения и события при формально сбалансированных скобках. Тридцать событий не имели доступного движку варианта ответа. Часть решений находилась вне контейнера `political_decisions`, а `ai_will_do` оказался самостоятельным решением без условий. В журнале последней личной кампании обнаружено 1 329 195 сообщений `effect_title`. Это свидетельство массового спама, но само по себе оно не устанавливает причину конкретного вылета.

Структура исправлена в обеих сборках. Проверка сравнением с резервными файлами обнаруживает прежние ошибки и больше не находит их в исправленных файлах. Сохранены ID событий, реестр и порядок стран, порядок партий, дерево технологий. Название одного из двух одноимённых решений Бенилюкса разделено.

В личной сборке партии Чинуков доступны с 1600 года и покрывают все 16 идеологий. Публичная копия сохраняет даты появления идеологий; 169 партийных записей, попавших туда из экспериментов, приведены к этим датам. Тестовые решения политической настройки в публичную версию не включены. Экспериментальные решения, выдававшие поздние морские технологии в XVII веке, удалены из публичного набора; местное заселение сохранено.

Верхняя палата показывает идеологии, а не отдельные партии. Для просмотра нескольких партий одного направления нужно открыть список выбора правящей партии; ограничения назначения определяются формой правления.

Для всех 6 849 ссылок на заголовки, описания и варианты ответа событий найдены строки локализации. Это проверка наличия текста, а не оценка качества каждого перевода. Название игры Victoria Ultimate оставлено в отключённом публичном мемном событии.

## Известные ограничения

- Игра не проверялась в работающем движке. Устранение всех вылетов, загрузка старого сохранения и создание нового файла сохранения не подтверждены. Для нового сохранения нужно вписать имя, например `TestSave1802`, а затем отдельно проверить его загрузку.
- В исходных шаблонах истории стран остаются ранние доли поздних идеологий и назначения партий у части преимущественно поздних или несуществующих в раннем сценарии стран. Дополнительный аудит отметил 553 таких доли и 37 назначений относительно базовой даты 1600 года. Это предупреждения о сценарной согласованности, а не доказанные причины вылета. Массовая перестройка всех сценариев в этот выпуск не включена. Начальный состав палаты Чинуков публичной версии исправлен отдельно.
- Семь событий испанской гражданской войны со страной SPF отключены ещё в alpha.4 из-за отсутствующего тега. Цепочка остаётся неполной.
- В основе отсутствуют 168 составов стартовых армий; ссылки на отсутствующие файлы были убраны ранее. Полноценное восстановление армий всех сценариев не выполнено.
- В карте есть 25 цветов без записей в таблице провинций. Цвета и геометрия карты не менялись, чтобы не вводить непроверенные изменения карты и её кэша.
- Сохраняются 23 пустых файла-заглушки и неподключённая история ARB. Их наличие не является само по себе критической ошибкой.
- Дополнительная проверка ресурсов отмечает 31 ссылку на отсутствующие старые эффекты, анимации и изображения, главным образом неиспользуемые элементы интерфейса и обучения. Их влияние в движке не подтверждено; вместо них не подставлялись произвольные ресурсы.
- При обновлении игры из старой версии может понадобиться пересобрать пользовательский кэш флагов. Из самого пакета устаревшие `flagfiles*` удалены. Сохранения и пользовательские кэши этим обновлением не удаляются.

## Повторная проверка

Нужен Python 3.10 или новее. Из корня репозитория:

```powershell
python tools/audit_mod.py "mod/Ultimate Ultimatum - Znamena idey" --historical --output audit-results.json
```

При наличии основной игры можно добавить `--base "D:/Games/Victoria 2"`. Код возврата 0 означает отсутствие ошибок, распознаваемых этим скриптом. Проверка не запускает игру и не обращается к сохранениям.
